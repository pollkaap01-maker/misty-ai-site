# MISTY AI — бесплатный статический сайт без CRM

В public/ находятся обычные HTML, CSS, JavaScript, изображения и 8 MP4-видео. Ни CRM, ни сервер Node.js, ни база данных, ни постоянный диск не нужны. Сайт не зависит от Sites или Tilda.

## Просмотр на компьютере

Распакуйте архив целиком и откройте public/index.html в браузере. Калькулятор и видео работают локально. Для отправки формы нужен опубликованный HTTPS-сайт.

## Бесплатное размещение Render

render.yaml описывает только Static Site, без платных Web Services и дисков. Publish Directory: public. Build Command пустой, сборки не требуется. Используйте адрес *.onrender.com, покупать домен необязательно. Подключение Git-репозитория и размещение выполняются в аккаунте владельца. Если Render предлагает оплатить сервер или диск, это не выбранная здесь конфигурация: ничего такого создавать не нужно.

У Render действуют собственные лимиты трафика и использования. Статический сайт не имеет задержки пробуждения серверного Free Web Service. Не включайте платные дополнения без отдельного согласования.

## Куда приходят заявки

Форма отправляет обращения через FormSubmit на pollkaap01@gmail.com по HTTPS. Регистрация CRM и пароль Gmail не нужны. FormSubmit — отдельный бесплатный сервис, у него действуют собственные правила и ограничения. Пример AJAX-запроса взят из официальной документации https://formsubmit.co/ajax-documentation.

Перед приёмом реальных обращений:
1. Опубликуйте сайт.
2. Отправьте с него тестовую заявку.
3. В pollkaap01@gmail.com откройте письмо FormSubmit (проверьте Спам) и подтвердите адрес.
4. Отправьте вторую тестовую заявку и убедитесь, что она пришла с параметрами калькулятора.

Пока эти действия не выполнены, доставка заявок не проверена. Успешный ответ API означает принятие сервисом отправки; он не гарантирует попадание письма во входящие. На сайте показывается ошибка при сетевом сбое или необходимости активации. Данные не сохраняются в CRM или браузере. Все параметры и предварительная цена включаются в письмо; это предварительный клиентский расчёт, окончательная цена согласуется со студией.

## Быстрая бесплатная публикация через GitHub Pages

Все файлы уже перенесены в pollkaap01-maker/misty-ai-site. В корне добавлены index.html и .nojekyll; статические файлы и ролики остаются в public/, дублирования видео нет. Оба способа размещения (Pages из корня и Render из public) проверены локально.

Чтобы включить Pages: Settings → Pages → Source: Deploy from a branch → Branch: main, Folder: / (root) → Save. После сборки GitHub покажет публичный адрес сайта. Этот шаг не выполнен автоматически: GitHub вернул 403 Resource not accessible by integration для API включения Pages, хотя запись файлов через подключение разрешена. Платные сервисы не создавались.

Настройки Render и отдельный public/index.html сохранены, если владелец предпочтёт Render. Форме по-прежнему нужны активация FormSubmit и настоящий URL политики конфиденциальности перед приёмом реальных обращений.
